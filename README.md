# My Portfolio
This project is a personal portfolio website developed using HTML, CSS, and JavaScript.
# Project Description
The website provides information about me, my projects, and a contact form. It also includes an interactive greeting message based on the time of day when the website is opened.
# Tools Used
HTML, CSS, and JavaScript
# How to Run
Open the index.html file in a web browser to view the portfolio.
# AI Use
AI tools were used to help with CSS design and fixing coding errors.
