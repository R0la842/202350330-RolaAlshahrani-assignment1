
# My Portfolio
## Project Description
This project is a personal portfolio website developed using HTML, CSS, and JavaScript. It introduces me as a Computer Science student and showcases my academic projects.
## How to Run Locally
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open the `index.html` file in a web browser such as Chrome, Firefox, Safari, or Edge.
4. The portfolio website will be displayed in the browser.
