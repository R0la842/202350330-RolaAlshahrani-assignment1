## Project Description

This project is a personal portfolio website developed using HTML, CSS, and JavaScript. It introduces me as a Computer Science student and showcases some of my academic projects.


## Features

- About Me section with a short introduction and tagline.
- Projects section showcasing two academic projects.
- Contact form with Name, Email, and Message fields.
- Responsive layout for desktop, tablet, and mobile screens.
- Interactive greeting message based on the time of day.

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

- `index.html` - Contains the structure and content of the portfolio website.
- `style.css ` - Contains the styling and responsive layout.
- `script.js` - Contains the JavaScript functionality.
- `docs/` - Contains the project documentation and AI usage report.

## How to Run Locally

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open the `index.html` file in a web browser such as Chrome, Firefox, Safari, or Edge.
4. The portfolio website will open in the browser.
