# AI Usage Report

## Tools Used & Use Cases

I used ChatGPT during this assignment to:
- Help me with the CSS design and layout.
- Help me understand and use CSS Grid and media queries for the responsive layout.
- Help me link images correctly.
- Explain how JavaScript connects with HTML using `getElementById()`.
- Help me identify and fix mistakes in my JavaScript code.
- Provide explanations and documentation support when needed.

## Benefits & Challenges

### Benefits

AI helped me understand the assignment requirements at the beginning because I was confused about what I needed to include. The examples and explanations helped me get a clearer picture of the project.
It also saved me time by helping me identify mistakes and providing alternative solutions within the same conversation.

### Challenges

I did not face any major challenges while using AI during this assignment. However, there were a few times when ChatGPT did not understand my question correctly, so I had to explain it again.

## Learning Outcomes

Through this assignment, I learned how to make a website responsive for different screen sizes and how to create an HTML page from scratch.
I also improved my understanding of CSS and JavaScript and learned how to connect different files in a web project.

## Responsible Use & Modifications

When ChatGPT suggested changes or modifications, I asked for an explanation before applying them. After understanding the suggested change, I implemented it myself and tested the website to check whether the problem was solved and whether the change was correct.
