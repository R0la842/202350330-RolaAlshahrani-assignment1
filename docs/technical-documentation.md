# Technical Documentation
## Project Structure
The project consists of an HTML file, a CSS file, a JavaScript file, and documentation files.
- index.html - Contains the structure and content of the portfolio website.
- style.css - Contains the styling and responsive layout of the website.
- script.js - Contains the JavaScript functionality for the interactive greeting message.
- README.md - Provides information about the project and how to run it.
- docs/ai-usage-report.md - Provides details about the use of AI during the assignment.
- docs/technical-documentation.md - Contains the technical documentation of the project.
## HTML Structure
The index.html file contains the main sections of the portfolio:
- About Me
- Projects
- Contact
It also links the CSS and JavaScript files.
## CSS
The style.css file is used to style the website. CSS Grid is used to organize the project section, while Flexbox is used for the contact form.
Media queries are used to make the website responsive on different screen sizes.
## JavaScript
The script.js file provides an interactive greeting message based on the time of day.
The message changes to:
- Good morning
- Good afternoon
- Good evening
## Testing
The website was tested in a web browser to check the layout, project images, contact form, and JavaScript greeting functionality.
